# STGR Branding

**Product:** STGR Browser — **Organization:** STEiGER Dojo

## Identity

| Token | Value |
|---|---|
| Product name | STGR Browser |
| Organization | STEiGER Dojo |
| Tagline | Built for speed. Designed for gamers. Private by default. |
| Style | minimal · premium · Japanese-dojo inspired · dark · technical · aggressive · elegant · gaming-oriented |

Never present STGR as official Mozilla Firefox. Where appropriate, say
"STGR Browser is based on Mozilla Firefox."

## Colors

| Token | Hex | Use |
|---|---|---|
| Black | `#080808` | primary background |
| Dark black | `#0D0D0D` | surfaces, panels |
| STGR red | `#E8202A` | **accent only** (tabs, focus, highlights) |
| Dark red | `#8F1018` | deep accents, gradients |
| Gold | `#C8A45D` | optional premium details |

Design rules:

- Red is an accent, **not a light show** — the UI must feel fast, quiet,
  precise, premium. Avoid excessive red.
- No RGB-gamer styling, no rounded "gamer" fonts. Technical, tight type.

## Logo

- Official master assets: `stgr/branding/stgr-logo.svg` (vector) and
  `stgr/branding/stgr-logo.png` (≥512×512, square) — **provided by
  STEiGER Dojo**. The current SVG is a clearly-marked placeholder; replace it,
  never ship the placeholder.
- Do not modify the logo artwork unless explicitly requested.
- Derived icons (`stgr/branding/icons/`, `stgr.ico`) are generated by
  `scripts/make_icons.py` — the logo is a project asset compiled into the
  browser; it is never downloaded at runtime and never served from a CDN.

## Where branding appears

Window title · About page (`stgr/ui/about/aboutStgr.html`) · Installer ·
Application metadata · Desktop/Start Menu shortcuts · File-association info ·
Browser UI · Settings · Update UI · Error pages where appropriate · App icons ·
Executable resources.

Applied through:

1. `stgr/config/stgr-config.json` + `stgr/branding/brand.json` (sources of truth)
2. `stgr/build/branding/` (the branding source staged into Firefox's
   in-tree `browser/branding/stgr` directory for `--with-branding`)
3. `patches/0001-stgr-branding.patch` (hardcoded chrome strings + attribution)
4. `patches/0003` / `patches/0005` (About page, chrome styling)
